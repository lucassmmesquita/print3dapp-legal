# Print3DApp — páginas públicas

Páginas de **suporte**, **política de privacidade** e **termos de uso** do app Print3DApp, publicadas pelo GitHub Pages:

- https://lucassmmesquita.github.io/print3dapp-legal/suporte.html
- https://lucassmmesquita.github.io/print3dapp-legal/privacidade.html
- https://lucassmmesquita.github.io/print3dapp-legal/termos.html

Este repositório contém apenas HTML estático gerado. O código do app fica em repositório privado; para atualizar, edite `config/brands/default/brand.json` lá e rode:

```bash
scripts/publish_site.sh default ../print3dapp-legal
```
